Red Hat Ansible Automation Platform (Managed Service)¶

動作確認済みのサービスと提供バージョン¶

対象本連携機能は、以下の環境において正常に動作することを確認しています。
  • Red Hat Ansible Automation Platform Service on AWS

    • Ansible Automation Platform 2.7

    • Automation Controller Version 4.8.1

    • Event-Driven Ansible Version 1.3.3

    • Automation Hub Version 4.12.2

警告

注意事項：連携先AAPのバージョンアップについて
各クラウドベンダーが提供する「Managed Service版（AWS/Azure）」は、ベンダー側のスケジュールでプラットフォームやAPIのアップデート（仕様変更）が自動で適用される場合があります。
これに伴い、サービスやAPIのアップデート、仕様変更などにより、本システムの連携機能が十全に機能しなくなる、または一部制限が生じる場合があります。
これらの不具合や仕様変更について、本システム側で永続的な動作を完全に保証するものではありません。本システム側では動作を完全に保証することはできかねますので、あらかじめご了承ください。
