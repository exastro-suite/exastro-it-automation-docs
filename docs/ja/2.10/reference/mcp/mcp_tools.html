MCPツール¶

本書は、ExastroのMCPツールについて記載したものです。

MCPツール一覧¶

MCPサーバーが提供しているMCPツールは以下になります。
ただし、利用するユーザーの権限によって使用可能なツールは変化します。※権限のないツールは tools/list の一覧に入らなくなります。
